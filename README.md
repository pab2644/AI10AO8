# MP-AI10AO8 Configuration

Веб-интерфейс для настройки модуля **MP-AI10AO8** (модуль аналоговых входов/выходов с поддержкой Modbus и BACnet).

Представляет собой одностраничное приложение (`index.html`), которое открывается в браузере и взаимодействует с HTTP API самого модуля. Интерфейс адаптирован в том числе для мобильных устройств (выдвижное боковое меню, touch-стили).

## Возможности

- **Авторизация** — вход в модуль по логину/паролю, смена пароля (раздел «Безопасность»).
- **Обзор / Мониторинг** — просмотр текущих значений аналоговых входов (AI) и выходов (AO), системная информация.
- **Входы (AI)** — настройка типов каналов, диапазонов (мин./макс.), коррекции, инициализации и описаний.
- **Выходы (AO)** — настройка каналов, управление выходом, поведение при потере связи.
- **Сеть** — DHCP / ручная настройка: IP-адрес, маска, шлюз, DNS.
- **Modbus** — адрес устройства, скорость (baud), чётность, стоп-биты, задержка.
- **BACnet** — параметры BACnet (порт и др.).
- **Время** — отображение текущего времени, синхронизация с ПК, установка времени.
- **Прошивка (Firmware)** — загрузка нового файла прошивки в модуль и перезагрузка.
- **Двуязычный интерфейс** — русский / английский (переключение языка, переводы встроены в страницу).

## Структура проекта

```
.
└── index.html   # Единый файл приложения: HTML + CSS + JavaScript (включая i18n и вызовы API)
```

## Запуск

Откройте `index.html` в браузере, либо раздайте его любым статическим сервером, например:

```bash
# Python
python3 -m http.server 8080

# или Node.js
npx serve .
```

Затем перейдите по адресу `http://localhost:8080`.

> **Примечание:** интерфейс обращается к API модуля по относительным путям (`MODULE_BASE_URL = ''`). Для полноценной работы страница должна обслуживаться самим модулем MP-AI10AO8 (или быть настроена через прокси/CORS на его адрес).

## HTTP API модуля

Используемые эндпоинты (методы GET/POST):

| Эндпоинт | Назначение |
|---|---|
| `/auth/login`, `/new/password` | Авторизация, смена пароля |
| `/current_state` | Текущие значения AI/AO |
| `/system/info` | Информация о системе |
| `/inputs/settings` | Настройки аналоговых входов |
| `/outputs/settings`, `/outputs/control`, `/outputs/state` | Настройки и управление выходами |
| `/network/settings` | Сетевые параметры |
| `/modbus/settings` | Параметры Modbus |
| `/bacnet/settings` | Параметры BACnet |
| `/time/current`, `/time/set`, `/time/service` | Работа со временем |
| `/firmware/load`, `/firmware/upload` | Обновление прошивки |
| `/reboot` | Перезагрузка модуля |

## Требования

- Любой современный браузер (Chrome, Firefox, Edge, Safari, включая мобильные).
- Внешние зависимости отсутствуют — всё содержимое находится в одном файле `index.html`.
